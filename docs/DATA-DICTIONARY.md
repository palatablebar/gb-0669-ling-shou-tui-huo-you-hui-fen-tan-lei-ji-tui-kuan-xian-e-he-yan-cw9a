# 数据定义

仅处理CNY；所有金额先用Decimal检查精度，再以整数分计算，不进行浮点累加。销售行须有正数量和单价，同订单的整单优惠与运费重复填写但只计算一次。同单SKU唯一，件数上限10000。整单优惠按每件单价最大余额分摊，余数相同时按SKU及件序确定。退货按原件序回收原实付，已退单位不重复使用；全部件数退完才返运费一次。退货按UTC与事件号排序，早于销售或超过数量的退货隔离且不改变已退款累计。退款账户按销售实例（订单号+销售时间）分账：订单号跨期复用时各实例独立核算，同一实例内多件商品共享整单优惠；退货按订单号、销售时间与商品归属唯一实例入账，归属不唯一时隔离ORDER_REUSED，不跨笔冲减。

- 空串、`-`、`N/A`、`NULL`、`未知`是缺失哨兵，不作为零。
- 原始批号、事件号均为文本，保留前导零。
- CSV支持UTF-8 BOM和GB18030，必须有完整表头，支持列顺序调整。
- 文件最大2MB、10000条记录；读取时逐记录校验，计算阶段保留受此上限约束的数据。
- 空文件、全空行、仅表头分别标记EMPTY_FILE、BLANK_ONLY、HEADER_ONLY。
- 多余列隔离；非法引号导致整次请求失败，不保存半批。
- 幂等键=输入字节摘要+规则版本+参数；内容完全相同复用批次。
- 复核采用整数版本比较，旧版本返回409。

单字段金额上限为1000000000000元，超过上限返回字段错误。
